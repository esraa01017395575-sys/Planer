# Pomodoro Timer Sound Effects

This directory contains sound effects for the Pomodoro timer.

## Required Files

Place the following MP3 files in this directory:

1. **click.mp3** - A short click/tap sound played when:
   - Starting the timer
   - Pausing the timer
   - Resetting the timer

2. **alarm.mp3** - An alarm/notification sound played when:
   - A Pomodoro session completes
   - A break period ends

## Sound Recommendations

### click.mp3
- Duration: 0.1 - 0.3 seconds
- Type: Soft click or tap sound
- Volume: Low to medium
- Example: A keyboard key press or mouse click sound

### alarm.mp3
- Duration: 2 - 5 seconds (can loop)
- Type: Pleasant notification sound
- Volume: Medium
- Example: A gentle bell, chime, or notification tone

## Where to Get Sounds

You can find free sound effects at:
- [Freesound.org](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

Search for:
- "click" or "tap" for click.mp3
- "notification", "bell", or "chime" for alarm.mp3

## Note

If sound files are missing, the timer will continue to work normally - sounds will simply be silent. The application handles missing audio files gracefully.
